# aplicación-de-entrada-de-datos
# 📝 Data Entry App

Aplicación de escritorio desarrollada en Python que permite ingresar datos de usuarios a través de una interfaz gráfica y almacenarlos automáticamente en un archivo Excel.

---

## 🚀 Demo

> Interfaz simple e intuitiva para la carga de datos.

---

## ✨ Características

* 📋 Formulario de ingreso de datos (Nombre, Apellido, Edad, Email)
* ✅ Validación de campos obligatorios
* 🔢 Validación de edad (solo números)
* 💾 Almacenamiento automático en archivo Excel (`.xlsx`)
* 🔄 Limpieza automática del formulario después de guardar
* 🎨 Interfaz personalizada con Tkinter

---

## 🛠️ Tecnologías utilizadas

* **Python**
* **Tkinter** (GUI)
* **openpyxl** (manejo de archivos Excel)

## ▶️ Instalación y uso

1. Clonar el repositorio:

```bash
git clone https://github.com/TU-USUARIO/data-entry-app.git
```

2. Entrar en la carpeta del proyecto:

```bash
cd data-entry-app
```

3. Instalar dependencias:

```bash
pip install openpyxl
```

4. Ejecutar la aplicación:

```bash
python main.py
```
